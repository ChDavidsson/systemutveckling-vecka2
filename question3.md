Vad innebär samarbete med GitHub? Vad är pull requests, branches och merge?

Samarbete med Github är att flera personer kan jobba med samma projekt samtidigt, utan att det stör varandra.
Branch är som ens egen version av main, som man jobbar med tills man är klar, sedan kan man stänga sin branch.
Pull request är det man gör när man har gjort en ändring i sin branch, så andra kan gå in och kolla om allt ser bra ut, sedan kan man merge-a.
Merge är när man slår samman en branch med main, detta efter att man har gått igenom en pull request.
